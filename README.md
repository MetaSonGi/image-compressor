사진 용량을 확 줄이는 웹앱 — 블로그·스토어·문서 등록용.


## 기능

- 🖼️ 여러 장 일괄 압축 (드래그 앤 드롭)
- 💾 저장 형식: WebP / JPG / PNG + 품질 슬라이더
- 📐 최대 너비 지정 리사이즈
- 📊 원본 vs 압축 후 용량·절약률 실시간 표시
- ⬇️ 개별 저장 / 전체 일괄 다운로드

## 기술

- Vanilla JS + Canvas 2D
- 100% 클라이언트 사이드 (서버 전송 없음)
